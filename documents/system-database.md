# 系统配置数据库

系统配置数据库存储应用级运行数据，由设置页面的“系统配置数据库”选择。关系型数据库连接配置仍保存在配置中心，系统库的连接标识保存在系统配置文档的 `system_database.connection_id` 中。

未配置系统库时，启动过程创建名为“sqlite3数据库”的 SQLite 连接，数据库文件位于应用数据目录下的 `zihuan_settings.sqlite3`。已有配置不可用时，启动失败并报告错误，不会自动切换到其他数据库。

系统库支持项目现有的 MySQL 和 SQLite 关系型数据库连接。MySQL 使用 `zihuan_settings` 数据库作为 schema，连接账号需要创建和访问该 schema 的权限。SQLite 将所选文件附加为 `zihuan_settings`，因此两种后端均通过 `zihuan_settings.model_usages` 访问模型用量。

设置页面和 Service 配置共用关系型数据库选择组件，支持搜索已有连接以及新增 MySQL、SQLite 连接。更换系统库时可以迁移数据、直接切换或取消。迁移在目标库事务中完成，成功后才持久化所选连接并切换运行时连接。迁移失败时继续使用原库，原库数据始终保留。重试迁移按记录标识去重，不覆盖目标库已有记录。迁移期间，模型用量读写等待切换完成。

`zihuan_core::migration` 集中定义并注册系统库的表结构升级和跨库数据迁移。已完成的升级记录在 `zihuan_settings.migrations` 中。新增系统数据表时，需要同时在迁移注册表中声明表结构和对应的数据迁移操作。

模型用量保存在 `model_usages` 表中，包含调用标识、模型配置标识、UTC 调用时间、token 数量、缓存命中率、输出速度和首 token 延迟。模型配置与时间组成联合索引。统计在数据库中聚合，默认累计指标覆盖全部历史，默认明细覆盖最近 32 天；指定时间范围时，累计指标和明细均使用该范围。

升级后首次初始化系统库时，迁移模块将旧的 `model_usage/usage.jsonl` 流式导入数据库，并在同一事务中记录导入完成状态。原文件保留但不再追加或读取。导入失败会回滚并阻止启动，修复后可以重试。选择“不迁移，直接切换”时不会导入旧文件，重启也不会补导入。
