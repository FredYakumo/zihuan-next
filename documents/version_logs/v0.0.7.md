# v0.0.7

## 功能

- 新增系统配置数据库
- 数据检索新增上下文显示，能直接看到Role Agent的上下文情况
- 优化推理上下文
- 优化Deep search qq message
- 优化sub agent机制
- DAG 节点可以作为工具调用
- 移除旧 python exec 工具，统一动态脚本引擎
- workspace 工具增强：ask user、edit file
- 会话fork功能增强
- 对话页展示子 agent 的运行过程
- 上下文用量统计层新增总用量显示
- 定时任务更可靠：任务失败自动重试、进程崩溃后残留任务可恢复，Dream 记忆整合改为定时任务运行
- 新建对话自动生成会话标题
- 脚本节点界面支持自定义样式，预览类节点（消息列表、字符串、QQ 消息）换用全新展示界面，图重新运行时节点界面自动重置
- 新增一键打包脚本（build.bat / build.ps1 / build.sh）和 Docker 镜像支持
- 优化Role Agent发送的格式
- 头像编辑器增强：缩放刻度尺、拖拽更稳健、头像字段移到顶部
- 设置页界面优化，新增通用下拉组件，定时任务与模型配置编辑器改进
- 优化UI
- 网页搜索引擎插件化
- 新增 brain_tool 插件类型：插件在清单里声明工具定义并实现 execute，即可作为工具提供给 Agent（issue #24）

## 修复

- 插件连接参数说明改为标题右侧的问号按钮，点击后以 tooltip 显示
- 修复 Web Search Provider 已选值未显示 Plugin 标记的问题
- 修复连接配置页遗漏连接列表绑定导致读取 `length` 报错、页面空白的问题
- 修复 embedding model 每次请求都重新加载weights、转换精度并复制tokenizer导致的推理延迟：运行实例复用模型和分词器，独立请求之间清空 KV cache，切换设备时rebuild model。
- 修复batch embedding 推理崩溃的问题，如Qwen3 因果掩码按整批声明形状却只填充一条序列，批量超过 1 时广播相加会越界 panic，改为单序列mask，相加时广播到批次与Attention head
- 修复保存连接、角色服务等配置时系统配置文档被整档覆盖的问题：`system_database` 等系统配置段不再丢失，系统库连接按数据库文件路径复用
- 修复一些报错
- 修复 Elasticsearch 记忆检索在非 Enterprise 授权下返回 403 的问题：改为分词检索与向量检索分别请求后在本地融合，不再依赖需要 Enterprise 授权的 RRF retriever
- 修复对话页面的一些异步竞态问题，特别是命令审批相关的
- 修复 qq chat 引用图片失败的问题
- 修复停止推理失败的问题
- 修复一个错误信息处理丢失
- 修复 data image explorer、Agent 配置页、cmd 相关的若干 bug
- 插件页支持查看动态脚本插件的详情（清单、依赖列表、可折叠的源代码预览：左侧文件树、右侧代码），并可直接卸载；新增「安装 zip 包」上传插件目录压缩包完成安装
- 修复一些工具的问题
- 修复sub agent 出错时日志记录不正确的问题
- 修复新增检索数据库后导入连接长时间无响应的问题
- 修复检索数据库连接配置 JSON 无法直接导入的问题
- 修复保存连接时界面无反馈的问题，并让数据库不可达时快速报错
- 检索数据库安装命令生成的连接配置改用用户填写的服务器地址，不再固定为 127.0.0.1
- 修复 QQ 聊天steer被注入后任务失败就永久丢失的问题：插嘴改为回复成功后才真正消费，推理异常结束时自动回滚重新排队
- 修复任务线程 panic 导致会话锁永久泄漏、该用户后续消息全部变成无人处理steer的问题：panic 时保证释放会话锁，并为会话锁增加 30 分钟泄漏看门狗
