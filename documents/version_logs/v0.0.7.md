# v0.0.7

Updated by GLM 5.3 Flash

## 功能

- 优化Deep search qq message
- 优化sub agent机制
- DAG 节点可以作为工具调用
- 移除旧 python exec 工具，统一动态脚本引擎
- workspace 工具增强：ask user、edit file
- 会话fork功能增强
- 对话页展示子 agent 的运行过程
- 上下文用量统计层新增总用量显示
- 定时任务更可靠：任务失败自动重试、进程崩溃后残留任务可恢复，Dream 记忆整合改为定时任务运行
- 新建对话自动生成会话标题
- 脚本节点界面支持自定义样式，预览类节点（消息列表、字符串、QQ 消息）换用全新展示界面，图重新运行时节点界面自动重置
- 新增一键打包脚本（build.bat / build.ps1 / build.sh）和 Docker 镜像支持
- 头像编辑器增强：缩放刻度尺、拖拽更稳健、头像字段移到顶部
- 设置页界面优化，新增通用下拉组件，定时任务与模型配置编辑器改进
- 优化UI
