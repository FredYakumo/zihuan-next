# v0.0.7

Updated by GLM 5.3 Flash

## 功能

- 深度搜索 QQ 消息增强：搜索改为 YAML 声明式配置驱动，统一 QQ 消息搜索入口，历史检索更准更稳
- 内置 agent（子 agent、记忆 agent、Dream agent）全部改为 YAML 声明式配置，可直接编辑定制
- 任意已注册的 DAG 节点都可以作为 agent 工具调用
- 移除旧 python exec 工具，统一动态脚本引擎（Python / JS 共用一套），WebUI 内置脚本编辑器
- workspace 工具增强：ask user、edit file
- 对话页支持会话 fork（从已有对话分叉新会话）
- 对话页展示子 agent 的运行过程
- 上下文用量统计层新增总用量显示
- 定时任务调度器重写：任务失败自动重试、进程崩溃后残留任务可恢复，Dream 记忆整合迁移为定时任务运行
- 头像编辑器增强：缩放刻度尺、拖拽更稳健、头像字段移到顶部
- 设置页 UI 重构，新增通用下拉组件，定时任务与模型配置编辑器改进

## 修复

- 修复对话页面的一些异步竞态问题，特别是命令审批相关的
- 修复 qq chat 引用图片失败的问题
- 修复停止推理失败的问题
- LLM 推理失败改为返回明确错误，而不是生成一条空泛的回复
- 修复 data image explorer、Agent 配置页、cmd 相关的若干 bug

## 优化

- 优化对话页面的UI：表格渲染、加载/刷新动画、exec cmd 结果展示、面板关闭按钮等
